# Столб неона в поле тяжести — проверка закона теплопроводности

Цель: при **равных температурах** нижней и верхней стенок измерить поток тепла через стенки.

| закон | предсказание при T_низ = T_верх = 300 K, g = 6e12 м/с² |
|---|---|
| q = −κ (dT/dz + Mg/C_v) (ноутбук) | поток вниз ≈ κ·Mg/C_v: нижняя стенка **забирает** тепло, верхняя **отдаёт**; в объёме перепад до Mg·H/C_v ≈ 155 K |
| q = −κ dT/dz (Фурье) | ноль в пределах шума; T(z) плоский |

Параметры: 400 атомов Ne (M = 20.18 г/моль), ячейка 5×5 нм периодическая по x,y, стенки z = ±8 нм
(ячейка по z ±10 нм — зазор 4 нм больше радиуса обрезки, атомы через z-периодичность не взаимодействуют),
g = −6·10¹² м/с² (mgH/RT ≈ 0.78: плотность внизу ≈ 2.2× выше, эффект хорошо различим), шаг 2 фс, 10 нс.

Стенки диффузные: отражённый атом получает скорость из распределения потока Максвелла при T стенки,
энергия, отданная газу, суммируется. В объёме термостата нет (`-E`).

## Запуск
1. Применить патч (один раз, в контейнере):
   `cd ~/winlibghemical/linux/release20111012 && patch -p1 < ghemical.release20111012.gravi_walls.patch`
   затем пересобрать libghemical и примеры (`make libghemical ghemical_examples` или `make all`).
2. `cd ~/moldyn/gravi_column && ./run_gravi_column.sh all` — три расчёта параллельно:
   `equal` (главный), `nog` (контроль без тяжести), `calib` (330/270 K без тяжести → κ).
3. `python3 analyze_gw.py *.gw.log`

κ из `calib`: κ = q / (60 K / 16 нм). Ожидаемый поток по закону ноутбука для `equal`: κ·Mg/C_v.
