# Столб неона в поле тяжести — проверка закона теплопроводности

Цель: при **равных температурах** стенок измерить поток тепла через стенки и профиль T(z).

| закон | предсказание при T_низ = T_верх = 300 K, g = 6e12 м/с² |
|---|---|
| q = −κ (dT/dz + Mg/C_v) (ноутбук) | поток вниз ≈ κ·Mg/C_v (нижняя стенка забирает, верхняя отдаёт) и/или градиент до −Mg/C_v ≈ −9.7 K/нм |
| q = −κ dT/dz (Фурье) | ноль в пределах шума; T(z) плоский |

## Сетап (полностью в патче gravi_walls, движок ghemical `eng1_mm_default_mim`)
- 400 атомов Ne (масса 20.18; тип не найден → LJ по умолчанию r=0.15 нм, ε=0.175 кДж/моль), ячейка 5×5×20 нм,
  периодика по x,y; по z стенки на ±8 нм (зазор 4 нм через границу ячейки > радиуса обрезки).
- Тяжесть: добавка g к ускорению по z.
- Стенки: гладкие плоскости без потенциала; атом, пересёкший стенку, зеркально отражается по z и получает
  **новую** скорость из распределения потока Максвелла при T стенки (полная аккомодация). Разность энергий
  копится в Q_lo / Q_hi. Других источников/стоков тепла нет (`-E`, с патчем v2 — и без стадий нагрева).
- Шаг 0.5 фс (2 фс неустойчиво).

## Патчи
- Дерево уже с v1 (`gravi_walls.patch` применён): применить **`ghemical.release20111012.gravi_walls_v2_incremental.patch`**.
- Чистое дерево: применить только **`ghemical.release20111012.gravi_walls_v2_full.patch`**.
- `gravi_walls_noheat.patch` больше **не нужен** (входит в v2; не применять вместе с v2).

v2 добавляет: `-E` без стадий нагрева/уравновешивания; `GW_SEED` задаёт и начальные скорости (srand);
в логе Ekin, Epot, Egrav=Σm|g|(z−zlo) и дрейф баланса энергии; профиль T(z) — по окнам, а не накопленный.

```bash
cd ~/winlibghemical/linux/release20111012

patch -p1 < ghemical.release20111012.gravi_walls_v2_incremental.patch

```

## Прогоны (2 нс каждый; ~4e6 шагов)

## Разбор
```bash
python3 analyze_gw.py equal_T300_g6_s1.gw.log equal_T300_g6_s2.gw.log nog_T300_g0_s1.gw.log \
        --calib calib_330_270_g0_s1.gw.log --skip 200 --plot
```
Выдаёт q_lo, q_hi, поток вверх с ошибкой по блокам, dT/dz, профили, дрейф энергии и — при `--calib` —
численные предсказания обоих законов в Вт/м² для сравнения с измеренным.

Проверка корректности: `drift` в v2-логе должен оставаться малым (≲ несколько кДж/моль при dt=0.5 фс).
